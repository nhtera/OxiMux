## Windows terminals

**A pane can run Git Bash or the command processor, not just PowerShell.**
Settings → Terminal → Default shell picks it; a second control picks the
PowerShell edition (auto pwsh 7, pwsh 7, or inbox Windows PowerShell).
PowerShell stays the default, so nothing changes for anyone who does not go
looking.

Resolution is deliberate about what it will accept. Git Bash is found through
the `OXIMUX_GIT_BASH_PATH` override, then the standard per-machine and per-user
(winget) install roots, then whatever the `git` on PATH belongs to — and a
WSL or Cygwin bash is never mistaken for it. The pwsh path prefers PowerShell 7,
rejects the zero-byte Store app-execution-alias stubs that ConPTY cannot launch,
and falls back through inbox PowerShell to `cmd.exe` so a terminal always opens.

Git Bash launches interactive **non**-login, which is not an oversight: a login
shell ignores the `--rcfile` the OSC-133 integration prepends, and the prompt
and output marks would be lost with it. A non-login interactive shell still
rebuilds the full MSYS PATH, and `MSYSTEM` / `CHERE_INVOKING` / `LANG` seed what
the skipped login profile would have set — a UTF-8 locale, and staying in the
pane's directory rather than `$HOME`.

The resolved program, argv and environment flow through the existing spawn
mirror, so in-process and relay-backed panes honour the choice alike, and a
non-empty free-form `shell` override still wins everywhere. The two settings
persist in `terminal.toml` as `windows_shell` and `windows_powershell`; absent
keys mean PowerShell and auto, so existing configs are untouched.

## Dictation

**The default speech model is whisper-turbo.** The old default paired
whisper-small with language auto-detect, which is the worst combination the
catalog offers to anyone who dictates in two languages. Measured through the
shipping CPU path on real speech: small + auto got English right and Vietnamese
wrong (*giọng* → *rọng*); pinning the language to Vietnamese fixed that and
destroyed English (*fox* → *"Quyệt Brown Fox chụp thật ra"*). So a bilingual
user is locked to auto, and the default model has to carry both languages
itself. whisper-turbo does — 19.8% against 31.7% Vietnamese WER — in a smaller
download, 537 MB against 610 MB.

The cost is latency: whisper pads every recording to a 30-second window, so the
encoder cost is near-constant per press, ~2.5s against ~0.9s. For
press-to-dictate, correctness wins that trade.

An existing `dictation.toml` keeps the model it recorded. A changed default
never re-points you at a model you have not downloaded.

## Settings

**The Voice pane's custom-words field gets the whole row.** A setting row pins
its control in a column measured on the control's own terms — right for a
switch, wrong for a text field, which carries no intrinsic width and collapsed
to its own padding. "Custom words" had been shipping as an unusable ~24px box.
Rows can now ask for the full width beneath their label; every other row keeps
the pinned shape.

**Opening the driver modal no longer waits on the driver check.** Pressing the
cog ran the verification synchronously before the card could paint — two
`codesign` subprocesses, a version read, and a SHA-256 over the whole ~53 MB
binary, ~200 ms every time the driver was actually installed. Nothing gates on
the answer at open time, so it now runs in the background and the pane renders
"Checking…" until it lands.

**The install row's chips no longer stack over the row below them.**

## Under the hood

**A committed ledger of reliability claims, checked in CI.** Each gate carries
its invariant, how a regression would present, and — the field that does the
work — the gap between where the invariant must hold and where it is actually
proven. The project's plan docs had twice carried a false "VERIFIED" row, and
neither was caught in review, because prose has no shape a reader can check.
Declaring `platforms` separately from `covered_platforms` gives the claim a
shape, and `xtask reliability-gates` checks it: it rejects duplicate ids,
missing test files, an assertion not defined in the file it cites, a coverage
claim wider than the declared platform list, an undocumented gap, and a
platform claimed by a file whose own crate-level `cfg` excludes it.

It is seeded with 16 gates from areas that actually broke, and 10 of them
declare a coverage gap. Writing them was the argument for the mechanism:
eleven rows were wrong in the first drafts, in both directions, every one from
assuming CI's shape instead of reading it.

**The desktop gates stopped rebuilding from zero on every run.** The Windows
gate took ~85 minutes because it was a cold build every time — nine cache
entries at 1–2.5 GB against a single 10 GB repository quota, so GitHub was
evicting continuously and the losers were the two most expensive entries to
rebuild.
